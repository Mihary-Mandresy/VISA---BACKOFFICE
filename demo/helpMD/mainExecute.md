# Compilation avec Main

Si vous voulez tester le code dans le main, il faut que vous commenter le `SpringApplication.run(DemoApplication.class, args);` dans le fichier **demo/src/main/java/com/visa/demo/DemoApplication.java** et apres vous metier votre teste dans le main, et si apres vous voulez lancer le serveur, vous n'a qu'à le décommenter.
